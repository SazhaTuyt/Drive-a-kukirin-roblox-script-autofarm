# 🚗 Drive A Kukirin Auto-Farm Script 🏎️

Найкращий та найшвидший безкоштовний скрипт для автоматичного фарму грошей у режимі **Drive A Kukirin** в Roblox. Отримуй мільйони монет без зайвих зусиль та купуй найкращі тачки за лічені хвилини! 💸

---

## ✨ Особливості (Features)

*   **⚡ Повністю автоматичний фарм (Auto-Farm):** Скрипт сам заробляє гроші 24/7, поки ти відпочиваєш.
*   **🛡️ Анти-бан система (Anti-Ban Bypass):** Безпечний алгоритм, який мінімізує ризик отримання бану.
*   **🚀 Оптимізація (Lag-Free):** Мінімальне навантаження на ПК, скрипт працює плавно навіть на слабких пристроях.
*   **🔄 Авто-приєднання (Auto-Rejoin):** Якщо гра вилетить, скрипт автоматично перезайде на сервер.
*   **💻 Зручний UI (Опціонально):** Гарний та зрозумілий інтерфейс для керування функціями (якщо використовується UI-бібліотека).

## 🛠️ Як використовувати (How to Use)

Для запуску скрипта тобі знадобиться будь-який робочий експлойт/інжектор для Roblox (наприклад: *Solara, Wave, Celery, Synapse Z* тощо).

1. Скопіюй код скрипта нижче (або візьми файл `script.lua` з цього репозиторія).
2. Запусти Roblox та зайди в режим **Drive A Kukirin**.
3. Відкрий свій експлойт та встав скопійований код у поле для виконання.
4. Натисни кнопку **Execute** (Виконати).
5. Насолоджуйся нескінченним потоком грошей! 🎉
